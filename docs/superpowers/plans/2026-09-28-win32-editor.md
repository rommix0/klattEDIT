# Win32 editor: implementation plan (plan 3 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `kpe.exe`, the 32-bit Klatt Parameter Editor. Its window is a left panel of parameter
checkboxes, stacked parameter strips, and a spectrogram strip with draggable formant tracks, all on one time
axis in ms. Around that:
- editing: painting, line tool, frame selection, cut/copy/paste/insert/delete, undo;
- a frame table, and New / Globals / Optimize / Parameter reference dialogs;
- playback, and CSV open/save plus WAV export.

**Architecture:** Plain Win32 C on top of plan 2's core.
- `view.c` (no Win32, unit-tested) does the geometry: strip layout, time and value mapping, ticks, picking the
  nearest formant.
- The Win32 files are thin: `main.c` (main window, menus, panel, status bar, file commands), `strips.c` (plot
  window), `table.c` (frame table), `dialogs.c` and `audio.c` (waveOut).
- They share one `kpe_app` state struct from `app.h`.
- After every committed edit, `app_changed()` re-synthesizes the document and refreshes every view.

**Tech Stack:** C (gnu11), Win32 API (Unicode `W` functions), comctl32 v6 (list views, status bar), comdlg32,
winmm, GDI; winlibs GCC 14.2 i686 with `windres`.

**Spec:** `docs/superpowers/specs/2026-09-28-kpe-open-design.md` (sections 5 and 8).
**Prerequisites:** plans 1 and 2 completed; `MAKE test` passes with 582 checks per architecture.

**Status of the code below:** built with no warnings. Two scripts drove the running program with synthetic
mouse, keyboard and menu messages and captured screenshots (both scripts are part of Task 7). They exercised
painting, the line tool, selection, the frame table with an in-place edit, the Globals, New, Optimize and
Parameter reference dialogs, and playback. Every screenshot matched the expected result.

## Global Constraints

- Everything in plans 1 and 2's Global Constraints applies (Git Bash, `MAKE` = `/c/winlibs/mingw32/bin/make.exe`,
  zero warnings, tabs and K&R braces, the commit trailer).
- `kpe.exe` is 32-bit only (built when `ARCH=32`). It links `klatt32.dll` through its import library and may
  import only system DLLs besides that.
- Unicode throughout: `wWinMain`, only `W` API functions, `wchar_t` paths. GUI files are always compiled with
  `-municode`, which defines `UNICODE`; the common-control macros (`ListView_*`) depend on it.
- The manifest requests common controls v6 and system DPI awareness. Every pixel size goes through `S(px)`, which
  scales 96-DPI pixels to the screen.
- The GUI files (`main.c`, `strips.c`, `table.c`, `dialogs.c`, `audio.c`) are excluded from the test runner by the
  Makefile's `GUI_SRC` list (plan 2). Anything that can be tested without a window goes in `view.c` or the plan 2
  core.
- The document changes only through the `doc_*` functions of `model.h`, so every edit can be undone.
- GUI code has no unit tests. Each GUI task ends with a compile check, and Tasks 6 and 7 verify the running
  program with screenshots and the manual checklist.

`kpe/view.h`:

```c
/* view.h - plot geometry: strip layout, time and value mapping, axis ticks, formant picking. No Win32. */
#ifndef KPE_VIEW_H
#define KPE_VIEW_H

#include "model.h"

#define FORMANT_STRIP (-1) /* the param of the spectrogram strip */

typedef struct {
	int param;       /* a KP_* index, or FORMANT_STRIP */
	int top, height; /* pixels */
} strip_rect;

/* Strip order: F0 AV AF AH AVS, the formant strip (always present), then B1 B2 B3 FNZ AN A1-A6 AB.
 * visible[p] selects the parameter strips; F1-F4 never get a strip of their own (they are drawn on the
 * formant strip). Parameter strips are unit pixels high with gap pixels between strips; the formant strip
 * takes the rest of height, but at least 2 * unit. Returns the number of strips written to out (at most NP). */
int view_layout(const int *visible, int top, int height, int unit, int gap, strip_rect *out);

/* A tick step of 1, 2 or 5 x 10^n such that ticks are at least min_px pixels apart when range spans pixels. */
double view_nice_step(double range, double pixels, double min_px);

/* The visible formant (KP_F1..KP_F4) whose value at frame is closest to hz, or -1 if none is visible. */
int view_nearest_formant(const kpe_doc *d, const int *visible, int frame, double hz);

/* The value range a strip shows: the parameter's limits, or 0..top_hz for the formant strip. */
void view_range(int param, double top_hz, double *lo, double *hi);

typedef struct {
	double t0_ms, ms_per_px; /* time at the left edge of the plot, and the zoom */
	int x0;                  /* pixel column of t0_ms */
} time_map;

double tm_x(const time_map *m, double t_ms);
double tm_t(const time_map *m, double x);
double vm_y(double v, double lo, double hi, int top, int height);
double vm_v(double y, double lo, double hi, int top, int height);

#endif
```

`kpe/view.c`:

```c
/* view.c - see view.h. */
#include <math.h>
#include "view.h"

static const int before[] = { KP_F0, KP_AV, KP_AF, KP_AH, KP_AVS };
static const int after[] = { KP_B1, KP_B2, KP_B3, KP_FNZ, KP_AN, KP_A1, KP_A2, KP_A3, KP_A4, KP_A5, KP_A6, KP_AB };

int view_layout(const int *visible, int top, int height, int unit, int gap, strip_rect *out)
{
	int n = 0, small = 0;
	for (unsigned i = 0; i < sizeof before / sizeof before[0]; i++)
		small += visible[before[i]] != 0;
	for (unsigned i = 0; i < sizeof after / sizeof after[0]; i++)
		small += visible[after[i]] != 0;
	int fh = height - small * (unit + gap);
	if (fh < 2 * unit)
		fh = 2 * unit;
	int y = top;
	for (unsigned i = 0; i < sizeof before / sizeof before[0]; i++)
		if (visible[before[i]]) {
			out[n++] = (strip_rect){ before[i], y, unit };
			y += unit + gap;
		}
	out[n++] = (strip_rect){ FORMANT_STRIP, y, fh };
	y += fh + gap;
	for (unsigned i = 0; i < sizeof after / sizeof after[0]; i++)
		if (visible[after[i]]) {
			out[n++] = (strip_rect){ after[i], y, unit };
			y += unit + gap;
		}
	return n;
}

double view_nice_step(double range, double pixels, double min_px)
{
	if (range <= 0 || pixels <= 0)
		return 1;
	double raw = range * min_px / pixels; /* the smallest step that keeps ticks min_px apart */
	double p = pow(10, floor(log10(raw)));
	for (int i = 0; i < 3; i++) {
		static const double m[3] = { 1, 2, 5 };
		if (m[i] * p >= raw - 1e-9 * p)
			return m[i] * p;
	}
	return 10 * p;
}

int view_nearest_formant(const kpe_doc *d, const int *visible, int frame, double hz)
{
	static const int f[4] = { KP_F1, KP_F2, KP_F3, KP_F4 };
	int best = -1;
	double bd = 0;
	if (frame < 0)
		frame = 0;
	if (frame >= d->nframes)
		frame = d->nframes - 1;
	for (int i = 0; i < 4; i++) {
		if (!visible[f[i]])
			continue;
		double dist = fabs(doc_get(d, frame, f[i]) - hz);
		if (best < 0 || dist < bd) {
			best = f[i];
			bd = dist;
		}
	}
	return best;
}

void view_range(int param, double top_hz, double *lo, double *hi)
{
	if (param == FORMANT_STRIP) {
		*lo = 0;
		*hi = top_hz;
		return;
	}
	klatt_param_info pi;
	KlattParamInfo(KLATT_FRAME, param, &pi);
	*lo = pi.min;
	*hi = pi.max;
}

double tm_x(const time_map *m, double t_ms)
{
	return m->x0 + (t_ms - m->t0_ms) / m->ms_per_px;
}

double tm_t(const time_map *m, double x)
{
	return m->t0_ms + (x - m->x0) * m->ms_per_px;
}

double vm_y(double v, double lo, double hi, int top, int height)
{
	return top + height - 1 - (v - lo) / (hi - lo) * (height - 1);
}

double vm_v(double y, double lo, double hi, int top, int height)
{
	double v = lo + (top + height - 1 - y) / (height - 1) * (hi - lo);
	return v < lo ? lo : v > hi ? hi : v;
}
```

```c
/* audio.c - playback through waveOut. The samples are copied, so the document may change while playing. */
#include <stdlib.h>
#include <string.h>
#include "app.h"
#include <mmsystem.h> /* after windows.h, which app.h includes */

static HWAVEOUT wo;
static WAVEHDR hdr;
static short *buf;
static int first_sample, rate;
static unsigned generation; /* tells a finished playback's notification from a stale one */

static void CALLBACK done(HWAVEOUT h, UINT msg, DWORD_PTR instance, DWORD_PTR p1, DWORD_PTR p2)
{
	(void)h;
	(void)p1;
	(void)p2;
	if (msg == WOM_DONE) /* only PostMessage is safe inside a waveOut callback */
		PostMessageW(app.main, WM_APP_PLAYDONE, (WPARAM)instance, 0);
}

int audio_play(const short *pcm, int n, int sr, int first, int count)
{
	audio_stop();
	if (first < 0)
		first = 0;
	if (first + count > n)
		count = n - first;
	if (count <= 0)
		return -1;
	buf = malloc(sizeof(short) * count);
	if (!buf)
		return -1;
	memcpy(buf, pcm + first, sizeof(short) * count);
	WAVEFORMATEX wf = { WAVE_FORMAT_PCM, 1, (DWORD)sr, (DWORD)sr * 2, 2, 16, 0 };
	generation++;
	if (waveOutOpen(&wo, WAVE_MAPPER, &wf, (DWORD_PTR)done, generation, CALLBACK_FUNCTION) != MMSYSERR_NOERROR) {
		wo = NULL;
		free(buf);
		buf = NULL;
		return -1;
	}
	memset(&hdr, 0, sizeof hdr);
	hdr.lpData = (LPSTR)buf;
	hdr.dwBufferLength = sizeof(short) * count;
	waveOutPrepareHeader(wo, &hdr, sizeof hdr);
	if (waveOutWrite(wo, &hdr, sizeof hdr) != MMSYSERR_NOERROR) {
		audio_stop();
		return -1;
	}
	first_sample = first;
	rate = sr;
	return 0;
}

void audio_stop(void)
{
	if (!wo)
		return;
	HWAVEOUT h = wo;
	wo = NULL; /* audio_playing() is false from here on */
	waveOutReset(h);
	waveOutUnprepareHeader(h, &hdr, sizeof hdr);
	waveOutClose(h);
	free(buf);
	buf = NULL;
}

int audio_playing(void)
{
	return wo != NULL;
}

double audio_pos_ms(void)
{
	if (!wo)
		return -1;
	MMTIME t;
	t.wType = TIME_SAMPLES;
	if (waveOutGetPosition(wo, &t, sizeof t) != MMSYSERR_NOERROR || t.wType != TIME_SAMPLES)
		return -1;
	return (first_sample + (double)t.u.sample) * 1000.0 / rate;
}

void audio_finished(WPARAM gen)
{
	if (gen == generation)
		audio_stop();
}
```

Notes for the reviewer:
- The samples are copied, so re-synthesis during playback is safe.
- A `waveOut` callback may only post messages, so `done()` posts `WM_APP_PLAYDONE` carrying the playback
  generation. `audio_finished` ignores a stale notification from a playback that was stopped and replaced.

```c
/* strips.c - the plot window: stacked parameter strips, the spectrogram strip with formant tracks, the shared
 * time axis, and painting, line drawing and selection with the mouse. */
#include <math.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <windows.h>
#include <windowsx.h>
#include "app.h"
#include "view.h"

enum { DRAG_NONE, DRAG_PAINT, DRAG_LINE, DRAG_SELECT };

static struct {
	int mode, param;
	double press_t, press_v, prev_t, prev_v, cur_t, cur_v;
	int press_x, press_frame;
} drag;

static struct {
	BITMAPINFO *bmi;       /* 8-bit greyscale DIB of the spectrogram up to app.spec_top_hz */
	unsigned char *bits;
	int w, h;
} dib;

static int ML(void) { return S(70); }  /* left margin: value labels and axis titles */
static int MR(void) { return S(40); }  /* right margin: formant labels */
static int MT(void) { return S(6); }
static int MB(void) { return S(44); }  /* time axis and selection ruler */

static int plot_width(void)
{
	RECT rc;
	GetClientRect(app.plot, &rc);
	int w = rc.right - ML() - MR();
	return w > 1 ? w : 1;
}

static time_map tmap(void)
{
	time_map m = { app.t0_ms, app.ms_per_px, ML() };
	return m;
}

static double frame_ms(void)
{
	return doc_frame_ms(&app.doc);
}

static int frame_at(double x)
{
	time_map m = tmap();
	int k = (int)lround(tm_t(&m, x) / frame_ms());
	return k < 0 ? 0 : k >= app.doc.nframes ? app.doc.nframes - 1 : k;
}

static int layout(strip_rect *s)
{
	RECT rc;
	GetClientRect(app.plot, &rc);
	return view_layout(app.visible, MT(), rc.bottom - MT() - MB(), S(64), S(8), s);
}

static COLORREF track_color(int p)
{
	switch (p) {
	case KP_F0: case KP_AV: return RGB(40, 110, 200);
	case KP_AF: return RGB(20, 140, 100);
	case KP_AH: return RGB(120, 100, 210);
	case KP_AVS: return RGB(160, 80, 160);
	case KP_F1: case KP_F2: case KP_F3: case KP_F4: return RGB(216, 90, 48);
	default: return RGB(90, 90, 90);
	}
}

/* ---- scrolling and zoom ---- */

void plot_sync_scroll(void)
{
	double dur = doc_duration_ms(&app.doc), page = plot_width() * app.ms_per_px;
	if (app.t0_ms > dur - page)
		app.t0_ms = dur - page;
	if (app.t0_ms < 0)
		app.t0_ms = 0;
	SCROLLINFO si = { .cbSize = sizeof si, .fMask = SIF_ALL | SIF_DISABLENOSCROLL, .nMax = (int)ceil(dur),
	                   .nPage = (UINT)page, .nPos = (int)app.t0_ms };
	SetScrollInfo(app.plot, SB_HORZ, &si, TRUE);
}

void plot_fit(void)
{
	app.t0_ms = 0;
	app.ms_per_px = doc_duration_ms(&app.doc) / plot_width();
	plot_sync_scroll();
	InvalidateRect(app.plot, NULL, FALSE);
}

/* Zooms by factor (< 1 zooms in) keeping the time at pixel x in place. */
static void zoom_at(double factor, double x)
{
	time_map m = tmap();
	double t = tm_t(&m, x), mpp = app.ms_per_px * factor;
	double lo = frame_ms() / S(40), hi = doc_duration_ms(&app.doc) / plot_width(); /* a frame is 40 px at most */
	if (mpp < lo)
		mpp = lo;
	if (mpp > hi)
		mpp = hi;
	app.t0_ms = t - (x - ML()) * mpp;
	app.ms_per_px = mpp;
	plot_sync_scroll();
	InvalidateRect(app.plot, NULL, FALSE);
}

void plot_zoom(double factor)
{
	zoom_at(factor, ML() + plot_width() / 2.0);
}

/* ---- spectrogram bitmap ---- */

void plot_new_spectrogram(void)
{
	free(dib.bmi);
	free(dib.bits);
	memset(&dib, 0, sizeof dib);
	if (!app.levels || app.spec.ncols <= 0)
		return;
	int rows = (int)ceil(app.spec_top_hz / app.spec.bin_hz) + 1;
	if (rows > app.spec.nbins)
		rows = app.spec.nbins;
	int stride = (app.spec.ncols + 3) & ~3;
	dib.bmi = calloc(1, sizeof(BITMAPINFOHEADER) + 256 * sizeof(RGBQUAD));
	dib.bits = malloc((size_t)stride * rows);
	if (!dib.bmi || !dib.bits) {
		free(dib.bmi);
		free(dib.bits);
		memset(&dib, 0, sizeof dib);
		return;
	}
	BITMAPINFOHEADER *bh = &dib.bmi->bmiHeader;
	bh->biSize = sizeof *bh;
	bh->biWidth = app.spec.ncols;
	bh->biHeight = rows; /* bottom-up: row 0 is 0 Hz */
	bh->biPlanes = 1;
	bh->biBitCount = 8;
	bh->biCompression = BI_RGB;
	bh->biClrUsed = 256;
	for (int i = 0; i < 256; i++) { /* darkness i: 0 = white, 255 = black */
		BYTE v = (BYTE)(255 - i);
		dib.bmi->bmiColors[i] = (RGBQUAD){ v, v, v, 0 };
	}
	for (int r = 0; r < rows; r++)
		for (int c = 0; c < app.spec.ncols; c++)
			dib.bits[(size_t)r * stride + c] = app.levels[(size_t)c * app.spec.nbins + r];
	dib.w = app.spec.ncols;
	dib.h = rows;
}

/* ---- painting ---- */

static void text_at(HDC dc, int x, int y, UINT align, const wchar_t *t)
{
	SetTextAlign(dc, align);
	TextOutW(dc, x, y, t, (int)wcslen(t));
}

static void line(HDC dc, int x0, int y0, int x1, int y1)
{
	MoveToEx(dc, x0, y0, NULL);
	LineTo(dc, x1, y1);
}

static void draw_track(HDC dc, const strip_rect *s, double lo, double hi, const double *vals, int first, int count,
                       int stride)
{
	time_map m = tmap();
	double fm = frame_ms();
	int k0 = (int)floor(app.t0_ms / fm) - 1, k1 = (int)ceil((app.t0_ms + plot_width() * app.ms_per_px) / fm) + 1;
	if (k0 < first)
		k0 = first;
	if (k1 > first + count - 1)
		k1 = first + count - 1;
	if (k1 < k0)
		return;
	POINT *pts = malloc(sizeof(POINT) * (k1 - k0 + 1));
	if (!pts)
		return;
	for (int k = k0; k <= k1; k++) {
		pts[k - k0].x = (LONG)lround(tm_x(&m, k * fm));
		pts[k - k0].y = (LONG)lround(vm_y(vals[(size_t)(k - first) * stride], lo, hi, s->top, s->height));
	}
	Polyline(dc, pts, k1 - k0 + 1);
	free(pts);
}

static void draw_strip(HDC dc, const strip_rect *s, HFONT vfont)
{
	int x0 = ML(), x1 = ML() + plot_width();
	double lo, hi;
	view_range(s->param, app.spec_top_hz, &lo, &hi);
	HRGN clip = CreateRectRgn(x0, s->top, x1 + 1, s->top + s->height);

	if (s->param == FORMANT_STRIP && dib.bits) {
		double step = app.spec.step_ms, dur = doc_duration_ms(&app.doc);
		double t_end = fmin(app.t0_ms + plot_width() * app.ms_per_px, dur);
		int src_x = (int)floor(app.t0_ms / step), src_w = (int)ceil((t_end - app.t0_ms) / step);
		if (src_x + src_w > dib.w)
			src_w = dib.w - src_x;
		double top_row_hz = (dib.h - 1) * app.spec.bin_hz; /* the DIB may end just above spec_top_hz */
		int dest_h = (int)lround(s->height * top_row_hz / app.spec_top_hz);
		SelectClipRgn(dc, clip);
		SetStretchBltMode(dc, HALFTONE);
		if (src_w > 0)
			StretchDIBits(dc, x0, s->top + s->height - dest_h, (int)lround((src_w * step) / app.ms_per_px), dest_h,
			              src_x, 0, src_w, dib.h, dib.bits, dib.bmi, DIB_RGB_COLORS, SRCCOPY);
		SelectClipRgn(dc, NULL);
	}

	/* value grid and labels */
	HPEN grid = CreatePen(PS_SOLID, 1, RGB(222, 222, 222));
	HPEN old = SelectObject(dc, grid);
	double step = view_nice_step(hi - lo, s->height, S(22));
	wchar_t t[64];
	SetTextColor(dc, RGB(90, 90, 90));
	for (double v = ceil(lo / step) * step; v <= hi + 1e-9; v += step) {
		int y = (int)lround(vm_y(v, lo, hi, s->top, s->height));
		if (s->param != FORMANT_STRIP)
			line(dc, x0, y, x1, y);
		line(dc, x0 - S(4), y, x0, y);
		swprintf(t, 64, L"%g", v);
		text_at(dc, x0 - S(6), y - S(7), TA_RIGHT | TA_TOP, t);
	}
	SelectObject(dc, old);
	DeleteObject(grid);

	/* axis title, rotated */
	klatt_param_info pi = { "Frequency", "Hz", "", 0, 0, 0 };
	if (s->param != FORMANT_STRIP)
		KlattParamInfo(KLATT_FRAME, s->param, &pi);
	swprintf(t, 64, L"%hs (%hs)", pi.name, pi.unit);
	HFONT of = SelectObject(dc, vfont);
	SetTextColor(dc, RGB(60, 60, 60));
	text_at(dc, S(4), s->top + s->height / 2, TA_CENTER | TA_TOP, t);
	SelectObject(dc, of);

	/* tracks */
	SelectClipRgn(dc, clip);
	if (s->param == FORMANT_STRIP) {
		for (int p = KP_F1; p <= KP_F4; p++) {
			if (!app.visible[p])
				continue;
			if (app.ghost[p]) {
				HPEN gp = CreatePen(PS_SOLID, 1, RGB(170, 170, 170));
				old = SelectObject(dc, gp);
				draw_track(dc, s, lo, hi, app.ghost[p], app.ghost_first, app.ghost_count, 1);
				SelectObject(dc, old);
				DeleteObject(gp);
			}
			HPEN pen = CreatePen(PS_SOLID, S(2), track_color(p));
			old = SelectObject(dc, pen);
			draw_track(dc, s, lo, hi, app.doc.frames + p, 0, app.doc.nframes, NP);
			SelectObject(dc, old);
			DeleteObject(pen);
		}
		/* F5 and F6 are globals: dashed constant lines */
		HPEN dash = CreatePen(PS_DOT, 1, RGB(216, 90, 48));
		old = SelectObject(dc, dash);
		SetBkMode(dc, TRANSPARENT);
		for (int i = 0; i < 2; i++) {
			double f = app.doc.globals[i ? KG_F6 : KG_F5];
			if (f <= hi) {
				int y = (int)lround(vm_y(f, lo, hi, s->top, s->height));
				line(dc, x0, y, x1, y);
			}
		}
		SelectObject(dc, old);
		DeleteObject(dash);
	} else {
		if (app.ghost[s->param]) {
			HPEN gp = CreatePen(PS_SOLID, 1, RGB(170, 170, 170));
			old = SelectObject(dc, gp);
			draw_track(dc, s, lo, hi, app.ghost[s->param], app.ghost_first, app.ghost_count, 1);
			SelectObject(dc, old);
			DeleteObject(gp);
		}
		HPEN pen = CreatePen(PS_SOLID, S(2), track_color(s->param));
		old = SelectObject(dc, pen);
		draw_track(dc, s, lo, hi, app.doc.frames + s->param, 0, app.doc.nframes, NP);
		SelectObject(dc, old);
		DeleteObject(pen);
	}
	SelectClipRgn(dc, NULL);
	DeleteObject(clip);

	/* formant labels in the right margin */
	if (s->param == FORMANT_STRIP) {
		int k = frame_at(x1);
		for (int i = 0; i < 6; i++) { /* F1-F4 from the frame at the right edge, F5 and F6 from the globals */
			double f = i < 4 ? doc_get(&app.doc, k, KP_F1 + i) : app.doc.globals[i == 4 ? KG_F5 : KG_F6];
			const char *name = i < 4 ? param_name(KLATT_FRAME, KP_F1 + i) : i == 4 ? "F5" : "F6";
			if ((i < 4 && !app.visible[KP_F1 + i]) || f > hi)
				continue;
			SetTextColor(dc, track_color(KP_F1));
			swprintf(t, 64, L"%hs", name);
			text_at(dc, x1 + S(4), (int)lround(vm_y(f, lo, hi, s->top, s->height)) - S(7), TA_LEFT | TA_TOP, t);
		}
	}

	/* frame */
	HBRUSH border = CreateSolidBrush(RGB(150, 150, 150));
	RECT r = { x0, s->top, x1 + 1, s->top + s->height };
	FrameRect(dc, &r, border);
	DeleteObject(border);
}

	GetObjectW(app.font, sizeof lf, &lf);

	time_map m = tmap();
	int x0 = ML(), x1 = ML() + plot_width(), ybot = rc.bottom - MB();

		RECT sr = { (LONG)tm_x(&m, app.sel_a * fm), MT(), (LONG)tm_x(&m, (app.sel_b + 1) * fm), ybot };

	}

	/* vertical time grid */
	double visible_ms = plot_width() * app.ms_per_px, tstep = view_nice_step(visible_ms, plot_width(), S(70));
	strip_rect strips[NP];
	int n = layout(strips);
	HPEN grid = CreatePen(PS_SOLID, 1, RGB(228, 228, 228));
	HPEN old = SelectObject(dc, grid);
	for (double t = ceil(app.t0_ms / tstep) * tstep; t <= app.t0_ms + visible_ms; t += tstep) {
		int x = (int)lround(tm_x(&m, t));
		for (int i = 0; i < n; i++)
			if (strips[i].param != FORMANT_STRIP)
				line(dc, x, strips[i].top, x, strips[i].top + strips[i].height);
	}
	SelectObject(dc, old);
	DeleteObject(grid);

	for (int i = 0; i < n; i++)
		draw_strip(dc, &strips[i], vfont);

	/* time axis */
	RECT ruler = { x0, ybot + S(2), x1 + 1, ybot + S(22) };
	FillRect(dc, &ruler, GetSysColorBrush(COLOR_BTNFACE));
	SetTextColor(dc, RGB(90, 90, 90));
	wchar_t t[32];
	for (double tt = ceil(app.t0_ms / tstep) * tstep; tt <= app.t0_ms + visible_ms + 1e-9; tt += tstep) {
		int x = (int)lround(tm_x(&m, tt));
		line(dc, x, ybot + S(2), x, ybot + S(7));
		swprintf(t, 32, L"%g", tt);
		text_at(dc, x, ybot + S(7), TA_CENTER | TA_TOP, t);
	}
	text_at(dc, (x0 + x1) / 2, ybot + S(24), TA_CENTER | TA_TOP, L"Time (ms)");

	/* cursor, playhead, line-tool preview */
	if (app.cursor >= 0) {
		HPEN cp = CreatePen(PS_DOT, 1, RGB(24, 95, 165));
		old = SelectObject(dc, cp);
		int x = (int)lround(tm_x(&m, app.cursor * fm));
		if (x >= x0 && x <= x1)
			line(dc, x, MT(), x, ybot);
		SelectObject(dc, old);
		DeleteObject(cp);
	}
	if (app.play_ms >= 0) {
		HPEN pp = CreatePen(PS_SOLID, S(2), RGB(200, 40, 40));
		old = SelectObject(dc, pp);
		int x = (int)lround(tm_x(&m, app.play_ms));
		if (x >= x0 && x <= x1)
			line(dc, x, MT(), x, ybot);
		SelectObject(dc, old);
		DeleteObject(pp);
	}
	if (drag.mode == DRAG_LINE) {
		for (int i = 0; i < n; i++) {
			int sp = strips[i].param;
			int match = sp == drag.param || (sp == FORMANT_STRIP && drag.param >= KP_F1 && drag.param <= KP_F4);
			if (!match)
				continue;
			double lo, hi;
			view_range(sp, app.spec_top_hz, &lo, &hi);
			HPEN lp = CreatePen(PS_DASH, 1, track_color(drag.param));
			old = SelectObject(dc, lp);
			line(dc, (int)tm_x(&m, drag.press_t), (int)vm_y(drag.press_v, lo, hi, strips[i].top, strips[i].height),
			     (int)tm_x(&m, drag.cur_t), (int)vm_y(drag.cur_v, lo, hi, strips[i].top, strips[i].height));
			SelectObject(dc, old);
			DeleteObject(lp);
		}
	}
	SelectObject(dc, of);
	DeleteObject(vfont);
}

static const strip_rect *strip_at(int y, strip_rect *strips, int n)
{
	for (int i = 0; i < n; i++)
		if (y >= strips[i].top && y < strips[i].top + strips[i].height)
			return &strips[i];
	return NULL;
}

/* Time and value of a point in a strip; values outside the strip are clamped to its range. */
static void point_value(const strip_rect *s, int x, int y, double *t, double *v)
{
	time_map m = tmap();
	double lo, hi;
	view_range(s->param, app.spec_top_hz, &lo, &hi);
	*t = tm_t(&m, x);
	*v = vm_v(y, lo, hi, s->top, s->height);
}

static void hover(int x, int y)
{
	strip_rect strips[NP];
	int n = layout(strips);
	RECT rc;
	GetClientRect(app.plot, &rc);
	if (x < ML() || x > ML() + plot_width()) {
		app_status(L"");
		return;
	}
	int k = frame_at(x);
	wchar_t t[256];
	int len = swprintf(t, 256, L"t = %g ms \x00B7 frame %d", k * frame_ms(), k);
	const strip_rect *s = strip_at(y, strips, n);
	if (s) {
		double lo, hi;
		view_range(s->param, app.spec_top_hz, &lo, &hi);
		if (s->param == FORMANT_STRIP) {
			for (int p = KP_F1; p <= KP_F4; p++)
				if (app.visible[p])
					len += swprintf(t + len, 256 - len, L"  %hs %g", param_name(KLATT_FRAME, p), doc_get(&app.doc, k, p));
			len += swprintf(t + len, 256 - len, L" \x00B7 pointer %g Hz", round(vm_v(y, lo, hi, s->top, s->height)));
		} else {
			klatt_param_info pi;
			KlattParamInfo(KLATT_FRAME, s->param, &pi);
			len += swprintf(t + len, 256 - len, L" \x00B7 %hs %g %hs \x00B7 pointer %g", pi.name,
			                doc_get(&app.doc, k, s->param), pi.unit, round(vm_v(y, lo, hi, s->top, s->height)));
		}
	}
	app_status(t);
}

static void mouse_down(HWND h, int x, int y, WPARAM keys)
{
	SetFocus(h);
	RECT rc;
	GetClientRect(h, &rc);
	strip_rect strips[NP];
	int n = layout(strips);
	if (x < ML() || x > ML() + plot_width())
		return;
	if (y >= rc.bottom - MB()) {
		drag.mode = DRAG_SELECT;
		drag.press_x = x;
		drag.press_frame = frame_at(x);
		SetCapture(h);
		return;
	}
	const strip_rect *s = strip_at(y, strips, n);
	if (!s)
		return;
	int p = s->param;
	double t, v;
	point_value(s, x, y, &t, &v);
	if (p == FORMANT_STRIP) {
		p = view_nearest_formant(&app.doc, app.visible, frame_at(x), v);
		if (p < 0)
			return;
	}
	drag.param = p;
	drag.press_t = drag.prev_t = drag.cur_t = t;
	drag.press_v = drag.prev_v = drag.cur_v = v;
	SetCapture(h);
	if (keys & MK_SHIFT) {
		drag.mode = DRAG_LINE;
	} else {
		char label[40];
		snprintf(label, sizeof label, "Paint %s", param_name(KLATT_FRAME, p));
		drag.mode = DRAG_PAINT;
		doc_begin(&app.doc, label);
		doc_paint(&app.doc, p, t, v, t, v);
	}
	InvalidateRect(h, NULL, FALSE);
}

static void mouse_move(HWND h, int x, int y)
{
	hover(x, y);
	if (drag.mode == DRAG_NONE)
		return;
	if (drag.mode == DRAG_SELECT) {
		int k = frame_at(x);
		if (abs(x - drag.press_x) >= S(3)) {
			app.sel_a = k < drag.press_frame ? k : drag.press_frame;
			app.sel_b = k < drag.press_frame ? drag.press_frame : k;
		}
		InvalidateRect(h, NULL, FALSE);
		return;
	}
	strip_rect strips[NP];
	int n = layout(strips);
	for (int i = 0; i < n; i++) {
		int sp = strips[i].param;
		if (sp == drag.param || (sp == FORMANT_STRIP && drag.param >= KP_F1 && drag.param <= KP_F4)) {
			point_value(&strips[i], x, y, &drag.cur_t, &drag.cur_v);
			break;
		}
	}
	if (drag.mode == DRAG_PAINT) {
		doc_paint(&app.doc, drag.param, drag.prev_t, drag.prev_v, drag.cur_t, drag.cur_v);
		drag.prev_t = drag.cur_t;
		drag.prev_v = drag.cur_v;
	}
	InvalidateRect(h, NULL, FALSE);
}

static void finish_drag(int x)
{
	int mode = drag.mode;
	drag.mode = DRAG_NONE;
	if (mode == DRAG_PAINT) {
		doc_end(&app.doc);
		app_changed(CHG_VALUES);
	} else if (mode == DRAG_LINE) {
		char label[40];
		snprintf(label, sizeof label, "Line %s", param_name(KLATT_FRAME, drag.param));
		doc_begin(&app.doc, label);
		doc_paint(&app.doc, drag.param, drag.press_t, drag.press_v, drag.cur_t, drag.cur_v);
		doc_end(&app.doc);
		app_changed(CHG_VALUES);
	} else if (mode == DRAG_SELECT) {
		if (abs(x - drag.press_x) < S(3)) {
			app.sel_a = -1;
			app_set_cursor(drag.press_frame, 0);
		} else {
			app_set_cursor(app.sel_a, 0);
		}
	}
}

static LRESULT CALLBACK plot_proc(HWND h, UINT msg, WPARAM wp, LPARAM lp)
{
	switch (msg) {
	case WM_PAINT: {
		PAINTSTRUCT ps;
		HDC dc = BeginPaint(h, &ps);
		RECT rc;
		GetClientRect(h, &rc);
		HDC mem = CreateCompatibleDC(dc);
		HBITMAP bmp = CreateCompatibleBitmap(dc, rc.right, rc.bottom);
		HBITMAP ob = SelectObject(mem, bmp);
		paint(mem, rc);
		BitBlt(dc, 0, 0, rc.right, rc.bottom, mem, 0, 0, SRCCOPY);
		SelectObject(mem, ob);
		DeleteObject(bmp);
		DeleteDC(mem);
		EndPaint(h, &ps);
		return 0;
	}
	case WM_ERASEBKGND:
		return 1;
	case WM_SIZE:
		plot_sync_scroll();
		InvalidateRect(h, NULL, FALSE);
		return 0;
	case WM_LBUTTONDOWN:
		mouse_down(h, GET_X_LPARAM(lp), GET_Y_LPARAM(lp), wp);
		return 0;
	case WM_MOUSEMOVE:
		mouse_move(h, GET_X_LPARAM(lp), GET_Y_LPARAM(lp));
		return 0;
	case WM_LBUTTONUP:
		if (drag.mode != DRAG_NONE) {
			finish_drag(GET_X_LPARAM(lp)); /* before ReleaseCapture, whose WM_CAPTURECHANGED then does nothing */
			ReleaseCapture();
		}
		return 0;
	case WM_CAPTURECHANGED:
		if (drag.mode == DRAG_PAINT || drag.mode == DRAG_LINE) /* capture lost mid-drag: keep what was painted */
			finish_drag(drag.press_x);
		return 0;
	case WM_MOUSEWHEEL: {
		POINT pt = { GET_X_LPARAM(lp), GET_Y_LPARAM(lp) };
		ScreenToClient(h, &pt);
		int notches = GET_WHEEL_DELTA_WPARAM(wp) / WHEEL_DELTA;
		if (GET_KEYSTATE_WPARAM(wp) & MK_CONTROL) {
			zoom_at(pow(0.8, notches), pt.x);
		} else {
			app.t0_ms -= notches * plot_width() * app.ms_per_px * 0.1;
			plot_sync_scroll();
			InvalidateRect(h, NULL, FALSE);
		}
		return 0;
	}
	case WM_HSCROLL: {
		SCROLLINFO si = { .cbSize = sizeof si, .fMask = SIF_ALL };
		GetScrollInfo(h, SB_HORZ, &si);
		double page = plot_width() * app.ms_per_px;
		switch (LOWORD(wp)) {
		case SB_LINELEFT: app.t0_ms -= page * 0.1; break;
		case SB_LINERIGHT: app.t0_ms += page * 0.1; break;
		case SB_PAGELEFT: app.t0_ms -= page; break;
		case SB_PAGERIGHT: app.t0_ms += page; break;
		case SB_THUMBTRACK: case SB_THUMBPOSITION: app.t0_ms = si.nTrackPos; break;
		}
		plot_sync_scroll();
		InvalidateRect(h, NULL, FALSE);
		return 0;
	}
	}
	return DefWindowProcW(h, msg, wp, lp);
}

ATOM plot_register(HINSTANCE inst)
{
	WNDCLASSEXW wc = { .cbSize = sizeof wc };
	wc.hInstance = inst;
	wc.lpfnWndProc = plot_proc;
	wc.hCursor = LoadCursor(NULL, IDC_CROSS);
	wc.lpszClassName = L"KpePlot";
	return RegisterClassExW(&wc);
}
```

### Task 4: The frame table

**Files:**
- Create: `kpe/table.c`

**Interfaces:**
- Consumes: `app`, `S`, `app_changed`, `app_set_cursor`, `param_name`; `doc_begin`, `doc_set`, `doc_end`,
  `doc_get`.
- Produces: `table_show`, `table_refresh`, `table_select`; the window class `KpeTable` titled "Frame table".

How it works:
- The list view is virtual (`LVS_OWNERDATA`): rows are frames, and the columns are Frame, time_ms and the 21
  frame parameters.
- F2 (on the last clicked parameter column, F0 at first) or a double-click opens an in-place `EDIT` over the
  cell. Enter or losing focus commits it as one undo step ("Edit F0"), and Escape cancels.
- Selecting a row moves the plot's cursor. The `syncing` flag stops the echo back when the plot moves the
  selection.

- [ ] **Step 1: Write the frame table**

`kpe/table.c`:

```c
/* table.c - View > Frame table: every frame's values in a virtual list view, editable in place. */
#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>
#include <windows.h>
#include <commctrl.h>
#include "app.h"

#define COL_FIRST_PARAM 2 /* columns: frame, time_ms, then the parameters */

static HWND list, editor;
static int edit_row, edit_col, last_col = COL_FIRST_PARAM + KP_F0, syncing;

static void end_edit(int commit)
{
	if (!editor)
		return;
	HWND e = editor;
	editor = NULL; /* before DestroyWindow, which sends WM_KILLFOCUS */
	if (commit) {
		wchar_t t[64], *end;
		GetWindowTextW(e, t, 64);
		double v = wcstod(t, &end);
		while (*end == L' ')
			end++;
		if (end != t && !*end) {
			char label[40];
			snprintf(label, sizeof label, "Edit %s", param_name(KLATT_FRAME, edit_col - COL_FIRST_PARAM));
			doc_begin(&app.doc, label);
			doc_set(&app.doc, edit_row, edit_col - COL_FIRST_PARAM, v);
			doc_end(&app.doc);
			app_changed(CHG_VALUES);
		} else {
			MessageBeep(MB_ICONWARNING);
		}
	}
	DestroyWindow(e);
	SetFocus(list);
}

static LRESULT CALLBACK editor_proc(HWND h, UINT msg, WPARAM wp, LPARAM lp, UINT_PTR id, DWORD_PTR ref)
{
	(void)id;
	(void)ref;
	if (msg == WM_GETDLGCODE)
		return DLGC_WANTALLKEYS;
	if (msg == WM_KEYDOWN && (wp == VK_RETURN || wp == VK_ESCAPE)) {
		end_edit(wp == VK_RETURN);
		return 0;
	}
	if (msg == WM_KILLFOCUS) {
		end_edit(1);
		return 0;
	}
	return DefSubclassProc(h, msg, wp, lp);
}

static void begin_edit(int row, int col)
{
	if (row < 0 || row >= app.doc.nframes || col < COL_FIRST_PARAM || col >= COL_FIRST_PARAM + NP)
		return;
	end_edit(1);
	RECT r;
	ListView_EnsureVisible(list, row, FALSE);
	ListView_GetSubItemRect(list, row, col, LVIR_BOUNDS, &r);
	wchar_t t[64];
	swprintf(t, 64, L"%g", doc_get(&app.doc, row, col - COL_FIRST_PARAM));
	editor = CreateWindowExW(0, L"EDIT", t, WS_CHILD | WS_VISIBLE | WS_BORDER | ES_AUTOHSCROLL | ES_RIGHT,
	                         r.left, r.top, r.right - r.left, r.bottom - r.top, list, NULL, app.inst, NULL);
	SendMessageW(editor, WM_SETFONT, (WPARAM)app.font, 0);
	SetWindowSubclass(editor, editor_proc, 1, 0);
	SendMessageW(editor, EM_SETSEL, 0, -1);
	SetFocus(editor);
	edit_row = row;
	edit_col = col;
}

static void add_column(int i, const wchar_t *name, int width)
{
	LVCOLUMNW c = { .mask = LVCF_TEXT | LVCF_WIDTH | LVCF_FMT, .fmt = LVCFMT_RIGHT, .cx = width, .pszText = (LPWSTR)name,
	                .iSubItem = i };
	ListView_InsertColumn(list, i, &c);
}

static LRESULT notify(NMHDR *nh)
{
	if (nh->code == LVN_GETDISPINFOW) {
		LVITEMW *it = &((NMLVDISPINFOW *)nh)->item;
		if (!(it->mask & LVIF_TEXT) || it->iItem >= app.doc.nframes)
			return 0;
		if (it->iSubItem == 0)
			swprintf(it->pszText, it->cchTextMax, L"%d", it->iItem);
		else if (it->iSubItem == 1)
			swprintf(it->pszText, it->cchTextMax, L"%g", it->iItem * doc_frame_ms(&app.doc));
		else
			swprintf(it->pszText, it->cchTextMax, L"%g", doc_get(&app.doc, it->iItem, it->iSubItem - COL_FIRST_PARAM));
		return 0;
	}
	if (nh->code == LVN_ITEMCHANGED) {
		NMLISTVIEW *lv = (NMLISTVIEW *)nh;
		if (!syncing && lv->iItem >= 0 && (lv->uNewState & LVIS_SELECTED) && !(lv->uOldState & LVIS_SELECTED))
			app_set_cursor(lv->iItem, 1);
		return 0;
	}
	if (nh->code == NM_CLICK || nh->code == NM_DBLCLK) {
		NMITEMACTIVATE *ia = (NMITEMACTIVATE *)nh;
		LVHITTESTINFO hi = { .pt = ia->ptAction };
		if (ListView_SubItemHitTest(list, &hi) >= 0 && hi.iSubItem >= COL_FIRST_PARAM) {
			last_col = hi.iSubItem;
			if (nh->code == NM_DBLCLK)
				begin_edit(hi.iItem, hi.iSubItem);
		}
		return 0;
	}
	if (nh->code == LVN_KEYDOWN && ((NMLVKEYDOWN *)nh)->wVKey == VK_F2) {
		begin_edit(ListView_GetNextItem(list, -1, LVNI_SELECTED), last_col);
		return 0;
	}
	return 0;
}

static LRESULT CALLBACK table_proc(HWND h, UINT msg, WPARAM wp, LPARAM lp)
{
	switch (msg) {
	case WM_SIZE:
		MoveWindow(list, 0, 0, LOWORD(lp), HIWORD(lp), TRUE);
		return 0;
	case WM_NOTIFY:
		return notify((NMHDR *)lp);
	case WM_CLOSE:
		end_edit(1);
		ShowWindow(h, SW_HIDE);
		return 0;
	}
	return DefWindowProcW(h, msg, wp, lp);
}

void table_show(void)
{
	if (!app.table) {
		WNDCLASSEXW wc = { .cbSize = sizeof wc };
		wc.hInstance = app.inst;
		wc.lpfnWndProc = table_proc;
		wc.hCursor = LoadCursor(NULL, IDC_ARROW);
		wc.lpszClassName = L"KpeTable";
		RegisterClassExW(&wc);
		app.table = CreateWindowExW(WS_EX_TOOLWINDOW, L"KpeTable", L"Frame table", WS_OVERLAPPEDWINDOW,
		                            CW_USEDEFAULT, CW_USEDEFAULT, S(900), S(420), app.main, NULL, app.inst, NULL);
		list = CreateWindowExW(0, WC_LISTVIEWW, L"", WS_CHILD | WS_VISIBLE | LVS_REPORT | LVS_OWNERDATA |
		                       LVS_SHOWSELALWAYS | LVS_SINGLESEL, 0, 0, 0, 0, app.table, NULL, app.inst, NULL);
		SendMessageW(list, WM_SETFONT, (WPARAM)app.font, 0);
		ListView_SetExtendedListViewStyle(list, LVS_EX_FULLROWSELECT | LVS_EX_GRIDLINES | LVS_EX_DOUBLEBUFFER);
		add_column(0, L"Frame", S(50));
		add_column(1, L"time_ms", S(60));
		for (int p = 0; p < NP; p++) {
			wchar_t t[16];
			swprintf(t, 16, L"%hs", param_name(KLATT_FRAME, p));
			add_column(COL_FIRST_PARAM + p, t, S(48));
		}
		RECT rc;
		GetClientRect(app.table, &rc);
		MoveWindow(list, 0, 0, rc.right, rc.bottom, TRUE);
		table_refresh();
		table_select(app.cursor);
	}
	ShowWindow(app.table, SW_SHOW);
	SetForegroundWindow(app.table);
}

void table_refresh(void)
{
	if (!list)
		return;
	end_edit(0);
	ListView_SetItemCountEx(list, app.doc.nframes, LVSICF_NOSCROLL | LVSICF_NOINVALIDATEALL);
	InvalidateRect(list, NULL, FALSE);
}

void table_select(int frame)
{
	if (!list || frame < 0 || frame >= app.doc.nframes)
		return;
	syncing = 1;
	ListView_SetItemState(list, -1, 0, LVIS_SELECTED | LVIS_FOCUSED);
	ListView_SetItemState(list, frame, LVIS_SELECTED | LVIS_FOCUSED, LVIS_SELECTED | LVIS_FOCUSED);
	ListView_EnsureVisible(list, frame, FALSE);
	syncing = 0;
}
```

### Task 5: Dialogs

**Files:**
- Create: `kpe/dialogs.c`

**Interfaces:**
- Consumes: `app`, `S`, `app_changed`, `param_name`; `opt_simplify` (plan 2); `doc_begin`, `doc_set`,
  `doc_end`, `doc_undo`, `doc_can_undo`, `doc_undo_label`; the IDD_/IDC_ IDs from `resource.h`.
- Produces: `dlg_globals`, `dlg_asknum`, `dlg_paramref`, `dlg_optimize`.

How each dialog works:
- **Globals / New:** one template, `IDD_GLOBALS`. The 18 global fields are generated at run time in two columns,
  each label showing the parameter's range. For New, a duration field is shown as well.
- **Optimize:**
  - *Preview* applies the optimization as an undo step labelled "Optimize" and keeps copies of the original
    tracks in `app.ghost[]`, which the plot draws faintly.
  - A second Preview (or Apply) first undoes the previous one, so the settings can change freely.
  - *Apply* keeps the step. *Cancel* undoes it.
  - The grid choices are only those that are a whole number of frames.

- [ ] **Step 1: Write the dialogs**

`kpe/dialogs.c`:

```c
/* dialogs.c - File > New and Parameters > Globals (one dialog), Parameters > Optimize, Help > Parameter
 * reference, and a small number prompt. */
#include <math.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <wchar.h>
#include <windows.h>
#include <commctrl.h>
#include "app.h"
#include "optimize.h"
#include "resource.h"

/* Reads a number from a dialog field; 1 on success. */
static int get_number(HWND dlg, int id, double *v)

/* Creates a label and an edit field per global inside the IDC_FIELDS frame; without the duration row
 * (Globals rather than New) the fields move up into its place. */
static void create_fields(HWND dlg, const double *g, int with_duration)
{
	RECT area, dur;
	GetWindowRect(GetDlgItem(dlg, IDC_FIELDS), &area);
	MapWindowPoints(NULL, dlg, (POINT *)&area, 2);
	if (!with_duration) {
		GetWindowRect(GetDlgItem(dlg, IDC_DURATION), &dur);
		MapWindowPoints(NULL, dlg, (POINT *)&dur, 2);
		area.top = dur.top;
	}
	RECT du = { 0, 0, 4, 14 }; /* a row is 14 dialog units high */
	MapDialogRect(dlg, &du);
	int row_h = du.bottom, col_w = (area.right - area.left) / 2, rows = (NG + 1) / 2;
	HFONT font = (HFONT)SendMessageW(dlg, WM_GETFONT, 0, 0);
	for (int i = 0; i < NG; i++) {
		klatt_param_info pi;
		KlattParamInfo(KLATT_GLOBAL, i, &pi);
		int x = area.left + (i / rows) * col_w, y = area.top + (i % rows) * row_h;
		wchar_t label[96];
		if (strcmp(pi.unit, "-") == 0)
			swprintf(label, 96, L"%hs (%g-%g)", pi.name, pi.min, pi.max);
		else
			swprintf(label, 96, L"%hs (%g-%g %hs)", pi.name, pi.min, pi.max, pi.unit);
		HWND s = CreateWindowExW(0, L"STATIC", label, WS_CHILD | WS_VISIBLE | SS_NOPREFIX, x, y + 2,
		                         col_w * 62 / 100, row_h - 2, dlg, NULL, app.inst, NULL);
		HWND e = CreateWindowExW(WS_EX_CLIENTEDGE, L"EDIT", L"", WS_CHILD | WS_VISIBLE | WS_TABSTOP | ES_AUTOHSCROLL,
		                         x + col_w * 62 / 100, y, col_w * 32 / 100, row_h - 2, dlg,
		                         (HMENU)(INT_PTR)(IDC_FIELD_BASE + i), app.inst, NULL);
		SendMessageW(s, WM_SETFONT, (WPARAM)font, 0);
		SendMessageW(e, WM_SETFONT, (WPARAM)font, 0);
		set_number(dlg, IDC_FIELD_BASE + i, g[i]);
	}
}

static int read_fields(HWND dlg, globals_args *a)
{
	double g[NG], dur = 0;
	wchar_t msg[160];
	for (int i = 0; i < NG; i++) {
		klatt_param_info pi;
		KlattParamInfo(KLATT_GLOBAL, i, &pi);
		if (!get_number(dlg, IDC_FIELD_BASE + i, &g[i]) || g[i] < pi.min || g[i] > pi.max) {
			swprintf(msg, 160, L"%hs must be a number from %g to %g.", pi.name, pi.min, pi.max);
			return reject(dlg, IDC_FIELD_BASE + i, msg);
		}
	}
	if (a->duration_ms) {
		if (!get_number(dlg, IDC_DURATION, &dur) || dur < g[KG_FRAME_MS] || dur > 600000) {
			swprintf(msg, 160, L"The duration must be from %g ms (one frame) to 600000 ms.", g[KG_FRAME_MS]);
			return reject(dlg, IDC_DURATION, msg);
		}
		*a->duration_ms = dur;
	}
	memcpy(a->globals, g, sizeof g);
	return 1;
}

static int previewed; /* an Optimize step from Preview is on the undo stack */

static void clear_ghosts(void)
{
	for (int p = 0; p < NP; p++) {
		free(app.ghost[p]);

static double tolerance_for(int p, double hz, double f0, double db)
{
	if (p == KP_F0)
		return f0;
	klatt_param_info pi;
	KlattParamInfo(KLATT_FRAME, p, &pi);
	return strcmp(pi.unit, "dB") == 0 ? db : hz;
}

/* Undoes an earlier preview, then optimizes the checked tracks as one undo step. Returns 1, or 0 if a field
 * is invalid. */
static int run_optimize(HWND dlg)
{
	double hz, f0, db;
	if (!get_number(dlg, IDC_TOL_HZ, &hz) || hz < 0)
		return reject(dlg, IDC_TOL_HZ, L"Enter a tolerance of 0 or more.");
	if (!get_number(dlg, IDC_TOL_F0, &f0) || f0 < 0)
		return reject(dlg, IDC_TOL_F0, L"Enter a tolerance of 0 or more.");
	if (!get_number(dlg, IDC_TOL_DB, &db) || db < 0)
		return reject(dlg, IDC_TOL_DB, L"Enter a tolerance of 0 or more.");
	if (previewed) {
		doc_undo(&app.doc);
		previewed = 0;
	}
	clear_ghosts();
	HWND tracks = GetDlgItem(dlg, IDC_TRACKS), grid_box = GetDlgItem(dlg, IDC_GRID);
	int grid = (int)SendMessageW(grid_box, CB_GETITEMDATA, SendMessageW(grid_box, CB_GETCURSEL, 0, 0), 0);
	int first = 0, count = app.doc.nframes;
	if (IsDlgButtonChecked(dlg, IDC_RANGE_SEL) == BST_CHECKED && app.sel_a >= 0) {
		first = app.sel_a;
		count = app.sel_b - app.sel_a + 1;
	}
	double *v = malloc(sizeof(double) * count);
	wchar_t summary[4096] = L"";
	int len = 0;
	if (!v)
		return 0;
	doc_begin(&app.doc, "Optimize");
	for (int p = 0; p < NP; p++) {
		if (!ListView_GetCheckState(tracks, p))
			continue;
		app.ghost[p] = malloc(sizeof(double) * count);
		for (int i = 0; i < count; i++)
			v[i] = doc_get(&app.doc, first + i, p);
		if (app.ghost[p])
			memcpy(app.ghost[p], v, sizeof(double) * count);
		double err;
		int kept = opt_simplify(v, count, first, grid, tolerance_for(p, hz, f0, db), &err);
		for (int i = 0; i < count; i++)
			doc_set(&app.doc, first + i, p, v[i]);
		klatt_param_info pi;
		KlattParamInfo(KLATT_FRAME, p, &pi);
		len += swprintf(summary + len, 4096 - len, L"%hs: %d -> %d breakpoints, max error %.3g %hs\r\n", pi.name,
		                count, kept, err, pi.unit);
	}
	doc_end(&app.doc);
	free(v);
	app.ghost_first = first;
	app.ghost_count = count;
	previewed = doc_can_undo(&app.doc) && strcmp(doc_undo_label(&app.doc), "Optimize") == 0;
	SetDlgItemTextW(dlg, IDC_SUMMARY, len ? summary : L"No tracks are ticked.");
	app_changed(CHG_VALUES);
	return 1;
}

static INT_PTR CALLBACK optimize_proc(HWND dlg, UINT msg, WPARAM wp, LPARAM lp)
{
	(void)lp;
	switch (msg) {
	case WM_INITDIALOG: {
		HWND tracks = GetDlgItem(dlg, IDC_TRACKS);
		ListView_SetExtendedListViewStyle(tracks, LVS_EX_CHECKBOXES | LVS_EX_FULLROWSELECT);
		RECT rc;
		GetClientRect(tracks, &rc);
		LVCOLUMNW col = { .mask = LVCF_WIDTH, .cx = rc.right - GetSystemMetrics(SM_CXVSCROLL) };
		ListView_InsertColumn(tracks, 0, &col);
		for (int p = 0; p < NP; p++) {
			wchar_t t[16];
			swprintf(t, 16, L"%hs", param_name(KLATT_FRAME, p));
			LVITEMW it = { .mask = LVIF_TEXT, .iItem = p, .pszText = t };
			ListView_InsertItem(tracks, &it);
			ListView_SetCheckState(tracks, p, app.visible[p]);
		}
		int sel = app.sel_a >= 0;
		EnableWindow(GetDlgItem(dlg, IDC_RANGE_SEL), sel);
		CheckRadioButton(dlg, IDC_RANGE_SEL, IDC_RANGE_ALL, sel ? IDC_RANGE_SEL : IDC_RANGE_ALL);
		HWND grid = GetDlgItem(dlg, IDC_GRID);
		double fm = doc_frame_ms(&app.doc);
		static const struct { const wchar_t *name; double ms; } grids[] = {
			{ L"Every frame", 0 }, { L"5 ms", 5 }, { L"10 ms", 10 } };
		for (int i = 0; i < 3; i++) {
			double frames = grids[i].ms ? grids[i].ms / fm : 1;
			if (fabs(frames - round(frames)) > 1e-9 || frames < 1)
				continue; /* not a whole number of frames */
			int at = (int)SendMessageW(grid, CB_ADDSTRING, 0, (LPARAM)grids[i].name);
			SendMessageW(grid, CB_SETITEMDATA, at, (LPARAM)lround(frames));
		}
		SendMessageW(grid, CB_SETCURSEL, SendMessageW(grid, CB_GETCOUNT, 0, 0) - 1, 0);
		set_number(dlg, IDC_TOL_HZ, 20);
		set_number(dlg, IDC_TOL_F0, 2);
		set_number(dlg, IDC_TOL_DB, 1);
		previewed = 0;
		return TRUE;
	}
	case WM_COMMAND:
		switch (LOWORD(wp)) {
		case IDC_PREVIEW:
			run_optimize(dlg);
			return TRUE;
		case IDOK: /* re-run, in case a setting changed after Preview */
			if (run_optimize(dlg)) {
				clear_ghosts();
				app_changed(CHG_VALUES);
				EndDialog(dlg, 1);
			}
			return TRUE;
		case IDCANCEL:
			if (previewed)
				doc_undo(&app.doc);
			previewed = 0;
			clear_ghosts();
			app_changed(CHG_VALUES);
			EndDialog(dlg, 0);
			return TRUE;
		}
		break;
	}
	return FALSE;
}

void dlg_optimize(HWND owner)
{
	DialogBoxParamW(app.inst, MAKEINTRESOURCEW(IDD_OPTIMIZE), owner, optimize_proc, 0);
}
```

Behaviour to check in review:
- **`app_changed`** re-synthesizes and recomputes the spectrogram every time: the spectrogram uses 50 dB of range
  (`spectro_levels(..., 50, ...)`) with a 2 ms step. It then clamps the cursor and selection, and updates the
  panel, title, status bar, table and plot.
- **Unsaved changes:** New, Open and closing the window ask about them first (`confirm_discard`).
- **Accelerators** are skipped while an `Edit` control has the keyboard, so Space and Delete work inside the
  frame table's editor.

```c
/* Recomputes the spectrogram of the current sound. */
static void respectro(void)
{
	spectro_free(&app.spec);
	free(app.levels);
	app.levels = NULL;
	if (app.snd.pcm && spectro_compute(app.snd.pcm, app.snd.n, app.snd.sr,
	                                   app.narrowband ? SPECTRO_NARROW_MS : SPECTRO_WIDE_MS, 2, &app.spec) == 0) {
		app.levels = malloc((size_t)app.spec.ncols * app.spec.nbins);
		if (app.levels)
			spectro_levels(&app.spec, 50, app.levels);
	}
	plot_new_spectrogram();
}

void app_changed(int what)
{
	(void)what; /* every change re-synthesizes: at 11025 Hz a whole document takes milliseconds */
	synth_result_free(&app.snd);
	int r = synth_doc(&app.doc, &app.snd);
	if (r < 0)
		app_error(KlattErrorText(r));
	respectro();
	if (app.cursor >= app.doc.nframes)
		app.cursor = app.doc.nframes - 1;
	if (app.sel_a >= app.doc.nframes)
		app.sel_a = -1;
	if (app.sel_b >= app.doc.nframes)
		app.sel_b = app.doc.nframes - 1;
	update_globals_text();
	update_title();
	update_status_info();
	table_refresh();
	plot_sync_scroll();
	InvalidateRect(app.plot, NULL, FALSE);
}

	if (csv_save(app.path, &app.doc, &r) < 0) {
		app_error(r.message);
		return 0;
	}
	update_title();
	return 1;
}

static int save_as(void)
{
	wchar_t path[MAX_PATH];
	wcsncpy(path, app.path, MAX_PATH);
	if (!ask_path(1, csv_filter, L"csv", path))
		return 0;
	wcscpy(app.path, path);
	return save();
}

/* Before discarding the document: 1 to go ahead, 0 to cancel. */
static int confirm_discard(void)
{
	if (!app.doc.dirty)
		return 1;
	int r = MessageBoxW(app.main, L"Save changes to this document?", L"Klatt Parameter Editor",
	                    MB_YESNOCANCEL | MB_ICONQUESTION);
	if (r == IDYES)
		return save();
	return r == IDNO;
}

static void open_path(const wchar_t *path)
{
	size_t len = wcslen(path);
	if (len >= 12 && _wcsicmp(path + len - 12, L".globals.csv") == 0) {
		app_error("Open the frame file (name.csv), not its globals file (name.globals.csv).");
		return;
	}
	kpe_doc d;
	csv_report r;
	if (csv_load(path, &d, &r) < 0) {
		app_error(r.message);
		return;
	}
	replace_doc(&d, path);
	char note[700] = "";
	if (r.message[0])
		snprintf(note, sizeof note, "%s\n", r.message);
	if (r.clamped)
		snprintf(note + strlen(note), sizeof note - strlen(note),
		         "%d values were outside their parameter's range and were clamped.\n", r.clamped);
	if (note[0])
		app_error(note);
}

static void cmd_new(void)
{
	if (!confirm_discard())
		return;
	double g[NG], dur = 800;
	default_globals(g);
	if (!dlg_globals(app.main, g, &dur))
		return;
	kpe_doc d;
	if (doc_new(&d, g, dur) < 0) {
		app_error("Out of memory.");
		return;
	}
	replace_doc(&d, L"");
}

static void cmd_open(void)
{
	wchar_t path[MAX_PATH] = L"";
	if (confirm_discard() && ask_path(0, csv_filter, L"csv", path))
		open_path(path);
}

static void cmd_export_wav(void)
{
	wchar_t path[MAX_PATH] = L"";
	if (!app.snd.pcm || !ask_path(1, L"WAV files (*.wav)\0*.wav\0", L"wav", path))
		return;
	if (wav_write(path, app.snd.pcm, app.snd.n, app.snd.sr) < 0)

/* ---- edit commands ---- */

static int has_selection(void)
{
	return app.sel_a >= 0 && app.sel_b >= app.sel_a;
}

static void copy_selection(void)
{
	int count = app.sel_b - app.sel_a + 1;
	double *c = malloc(sizeof(double) * NP * count);
	if (!c)
		return;
	doc_copy_frames(&app.doc, app.sel_a, count, c);
	free(app.clip);
	app.clip = c;
	app.nclip = count;
}

static void cmd_delete(void)
{
	if (!has_selection())
		return;
	if (doc_delete_frames(&app.doc, app.sel_a, app.sel_b - app.sel_a + 1) < 0) {
		app_error("The whole document cannot be deleted; at least one frame must remain.");
		return;
	}
	app.cursor = app.sel_a;
	app.sel_a = -1;
	app_changed(CHG_FRAMES);
}

static int insert_point(void)
{
	if (has_selection())
		return app.sel_a;
	return app.cursor >= 0 ? app.cursor : app.doc.nframes;
}

static void cmd_paste(void)
{
	if (!app.clip)
		return;
	int at = insert_point();
	if (doc_insert_frames(&app.doc, at, app.nclip, app.clip) == 0) {
		app.sel_a = at;
		app.sel_b = at + app.nclip - 1;
		app_changed(CHG_FRAMES);
	}
}

static void cmd_insert(void)
{
	static double ms = 50;
	if (!dlg_asknum(app.main, L"Insert frames", L"Duration to insert (ms):", &ms, doc_frame_ms(&app.doc), 60000))
		return;
	int count = (int)(ms / doc_frame_ms(&app.doc) + 0.5);
	int at = insert_point();
	if (doc_insert_frames(&app.doc, at, count, NULL) == 0) {
		app.sel_a = at;
		app.sel_b = at + count - 1;
		app_changed(CHG_FRAMES);
	}
}

static void cmd_globals(void)
{
	double g[NG];
	memcpy(g, app.doc.globals, sizeof g);
	if (!dlg_globals(app.main, g, NULL))
		return;
	int r = doc_set_globals(&app.doc, g);
	if (r < 0) {
		app_error("Out of memory.");
		return;
	}
	app_changed(CHG_ALL);
	if (r == 1) {
		char m[160];
		snprintf(m, sizeof m, "The frames were resampled to %g ms; the duration is unchanged.", doc_frame_ms(&app.doc));
		app_error(m);
		plot_fit();
	}
}

static void play(int selection)
{
	if (audio_playing()) {
		audio_stop();
		app.play_ms = -1;
		InvalidateRect(app.plot, NULL, FALSE);
		return;
	}
	if (!app.snd.pcm)
		return;
	int first = 0, count = app.snd.n;
	if (selection) {
		if (!has_selection())
			return;
		double fm = doc_frame_ms(&app.doc);
		first = (int)(app.sel_a * fm * app.snd.sr / 1000);
		count = (int)((app.sel_b + 1) * fm * app.snd.sr / 1000) - first;
	}
	if (audio_play(app.snd.pcm, app.snd.n, app.snd.sr, first, count) < 0) {
		app_error("The sound device could not be opened.");
		return;
	}
	SetTimer(app.main, 1, 30, NULL);
}

static LRESULT CALLBACK main_proc(HWND h, UINT msg, WPARAM wp, LPARAM lp)
{
	switch (msg) {
	case WM_SIZE:
		layout();
		return 0;
	case WM_COMMAND:
		command(LOWORD(wp));
		return 0;
	case WM_INITMENUPOPUP:
		init_menu(GetMenu(h));
		return 0;
	case WM_TIMER:
		app.play_ms = audio_pos_ms();
		if (app.play_ms < 0)
			KillTimer(h, 1);
		InvalidateRect(app.plot, NULL, FALSE);
		return 0;
	case WM_APP_PLAYDONE:
		audio_finished(wp);
		if (!audio_playing()) {
			app.play_ms = -1;
			KillTimer(h, 1);
			InvalidateRect(app.plot, NULL, FALSE);
		}
		return 0;
	case WM_CLOSE:
		if (confirm_discard())
			DestroyWindow(h);
		return 0;
	case WM_DESTROY:
		audio_stop();
		PostQuitMessage(0);
		return 0;
	}
	return DefWindowProcW(h, msg, wp, lp);
}
```

```python
"""Writes samples/ba.csv: a /ba/-like syllable for trying the editor. Run from the repository root."""


def lerp(pts, t):
    for (t0, v0), (t1, v1) in zip(pts, pts[1:]):
        if t <= t1:
            return v0 + (v1 - v0) * (t - t0) / (t1 - t0) if t1 > t0 else v1
    return pts[-1][1]


TRACKS = {
    "AV": [(0, 0), (95, 0), (112, 60), (600, 60), (700, 0), (800, 0)],
    "AF": [(0, 0), (86, 0), (92, 55), (102, 55), (108, 0), (800, 0)],
    "AH": [(0, 0), (640, 0), (680, 45), (720, 0), (800, 0)],
    "F0": [(0, 110), (250, 125), (500, 110), (700, 95), (800, 95)],
    "F1": [(0, 450), (100, 250), (160, 700), (600, 700), (700, 600), (800, 450)],
    "F2": [(0, 1450), (100, 1100), (180, 1250), (600, 1250), (700, 1350), (800, 1450)],
    "F3": [(0, 2450), (100, 2200), (180, 2600), (600, 2600), (800, 2450)],
    "A5": [(0, 50), (800, 50)],
    "A6": [(0, 50), (800, 50)],
}

with open("samples/ba.csv", "w", newline="") as f:
    f.write("time_ms," + ",".join(TRACKS) + "\r\n")
    for k in range(160):
        t = k * 5
        f.write(f"{t}," + ",".join(str(round(lerp(p, t))) for p in TRACKS.values()) + "\r\n")
```

```c
/* Golden-file regression: every sample document is synthesized and written to golden_<name>.raw in the working
 * directory. Once the user has listened and approved, `make golden` copies those files to tests/golden/; from
 * then on this suite fails if the synthesis of a sample changes by more than 1 LSB. */
#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>
#include "test.h"
#include "csvio.h"
#include "synthrun.h"

static const wchar_t *samples[] = { L"ba" };

/* Reads a raw 16-bit file; returns the sample count, or -1 if it does not exist. */
static long read_raw(const wchar_t *path, short **out)
{
	FILE *f = _wfopen(path, L"rb");
	if (!f)
		return -1;
	fseek(f, 0, SEEK_END);
	long n = ftell(f) / (long)sizeof(short);
	fseek(f, 0, SEEK_SET);
	*out = malloc(sizeof(short) * (n > 0 ? n : 1));
	n = (long)fread(*out, sizeof(short), n, f);
	fclose(f);
	return n;
}

void suite_golden(void)
{
	for (size_t i = 0; i < sizeof samples / sizeof samples[0]; i++) {
		wchar_t path[260];
		kpe_doc d;
		csv_report r;
		synth_result s;
		swprintf(path, 260, L"../../samples/%ls.csv", samples[i]); /* the runner works in build/32 or build/64 */
		CHECK(csv_load(path, &d, &r) == 0);
		CHECK(synth_doc(&d, &s) == 0);
		swprintf(path, 260, L"golden_%ls.raw", samples[i]);
		FILE *f = _wfopen(path, L"wb");
		CHECK(f != NULL);
		if (f) {
			fwrite(s.pcm, sizeof(short), s.n, f);
			fclose(f);
		}
		short *g;
		swprintf(path, 260, L"../../tests/golden/%ls.raw", samples[i]);
		long n = read_raw(path, &g);
		if (n < 0) {
			printf("  %ls: no approved golden file yet (see make golden)\n", samples[i]);
		} else {
			int worst = 0;
			CHECK(n == s.n);
			for (long k = 0; k < n && k < s.n; k++) {
				int diff = abs(g[k] - s.pcm[k]);
				if (diff > worst)
					worst = diff;
			}
			CHECK(worst <= 1);
			free(g);
		}
		synth_result_free(&s);
		doc_free(&d);
	}
}
```
