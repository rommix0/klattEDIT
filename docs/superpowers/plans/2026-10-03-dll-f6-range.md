# Klatt DLL 1.3: F6 up to 8000 Hz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise the DLL's upper limit for the global F6 from 4999 Hz to 8000 Hz (DLL version 1.3.0), so a voice built at 16 kHz can place its sixth formant where the speaker has it.

**Architecture:** One row of the global parameter table (`klatt/params.c`) changes; the synthesizer already keeps every frequency below SR/2 (`fmin(F6, fmax)`) and bypasses a resonator at or above 0.45 SR (`K_BYPASS`), so no signal-path code changes. The version goes to 1.3.0 and the docs record the new limit. F6's default stays 4900, so the golden render and every document that does not set F6 above 4999 are bit-identical.

**Tech Stack:** C (gnu11), MinGW-w64 (winlibs) 32- and 64-bit, the hand-rolled test runner (`tests/test.h`), GNU make.

**Spec:** `docs/superpowers/specs/2026-09-28-klattedit-design.md` (the parameter table; the F6 row changes here) and `docs/klatt-dll.md` (the DLL's reference).

**Why (the user's request, from the formant voice builder):** that project fits a voice for this DLL to the CMU ARCTIC BDL corpus at 16 kHz. 16 kHz LPC on BDL's reliable vowel frames puts F6 at 5572 Hz (median); clamped to 4999, the rendered voice stays 10-15 dB below BDL above about 5.5 kHz. The user asked to lift the clamp. 8000 Hz covers a 16 kHz voice up to its Nyquist frequency; at higher sample rates (SR goes to 20000) F6 can still lie up to 8000.
